# Recommendation System

[![TensorFlow](https://img.shields.io/badge/TensorFlow-2.16.1-orange)](https://www.tensorflow.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A collaborative filtering-based recommendation system built with TensorFlow/Keras to predict user ratings for movies using the MovieLens-20M dataset.

## Key Features
- **Collaborative Filtering Model**: Neural network architecture with user and movie embedding layers.
- **TensorFlow Integration**: Scalable training on large datasets.
- **Real-World Dataset**: Trained on the MovieLens-20M dataset (20 million ratings).
- **Evaluation Metrics**: Mean Absolute Error (MAE) of **0.85** on test data.

## Prerequisites
- Python 3.8+
- TensorFlow 2.16.1
- pandas, numpy, scikit-learn
